# Git Commands & Deployment Instructions
# Cybersecurity Risk Management Dashboard

## Part 1: Initialize Git & GitHub Setup

### 1. Initialize Local Git Repository

```bash
cd crmd
git init
git config user.name "Your Name"
git config user.email "your.email@example.com"
```

### 2. Create .gitignore (Already Included)

The `.gitignore` file is included in the project. It excludes:
- IDE files (.vscode, .idea)
- Logs and temporary files
- Sensitive files (.env)
- Node modules and vendor directories

### 3. Add All Files to Git

```bash
git add .
```

### 4. Create Initial Commit

```bash
git commit -m "Initial commit: CRMD v1.0 - Cybersecurity Risk Management Dashboard"
```

### 5. Create GitHub Repository

1. Go to https://github.com/new
2. Enter Repository name: `crmd`
3. Add description: "Cybersecurity Risk Management Dashboard - ATC Final Year Project"
4. Choose Public or Private
5. Click "Create repository"
6. Copy the HTTPS URL (e.g., https://github.com/yourusername/crmd.git)

### 6. Add Remote & Push to GitHub

```bash
git remote add origin https://github.com/yourusername/crmd.git
git branch -M main
git push -u origin main
```

### 7. Verify on GitHub

- Visit your repository: https://github.com/yourusername/crmd
- Check that all files are uploaded
- Verify .gitignore is working (no .env or logs)

## Part 2: Deployment to Render.com

### 1. Create Render Account

1. Go to https://render.com
2. Click "Sign Up"
3. Use your GitHub account to authenticate (recommended)
4. Verify email

### 2. Set Up Remote MySQL Database

Choose ONE of these options:

#### Option A: Aiven (Recommended - Free Tier)

```bash
1. Go to https://aiven.io
2. Click "Sign Up"
3. Verify email
4. Create new project
5. Add MySQL database service
6. Select "Startup-4" (free tier)
7. Choose region closest to you
8. Create service and wait 2-3 minutes
9. Go to "Connection Info" tab
10. Copy these details:
    - Service Name: <your-service>
    - Host: <mysql-xxxxx.a.aivencloud.com>
    - Port: <usually 3306>
    - User: avnadmin
    - Password: <auto-generated>
    - Database: defaultdb
```

Connection String Example:
```
mysql://avnadmin:password@mysql-abc123.a.aivencloud.com:3306/defaultdb
```

#### Option B: FreeMySQL

```bash
1. Go to https://www.freemysqlhosting.net
2. Register an account
3. Create new database
4. Get details from email:
    - Host: sql6.freemysqlhosting.net
    - User: <username>
    - Password: <password>
    - Database: <database>
```

#### Option C: Clever Cloud

```bash
1. Go to https://www.clever-cloud.com
2. Sign up
3. Add MySQL addon
4. Get connection details from dashboard
```

### 3. Import Database on Remote Host

Once you have your remote MySQL credentials:

#### Using phpMyAdmin (if available):
```bash
1. Login to phpMyAdmin on remote host
2. Create new database: crmd_db
3. Click Import tab
4. Upload sql/database.sql
5. Click Import
```

#### Using Command Line:
```bash
mysql -h <host> -u <user> -p <database> < sql/database.sql
```

Replace with your actual credentials:
```bash
mysql -h sql6.freemysqlhosting.net -u sql6xxxxx_0 -p sql6xxxxx_0 < sql/database.sql
```

Then enter your password when prompted.

### 4. Connect GitHub to Render

1. Go to https://render.com/dashboard
2. Click "New +"
3. Select "Web Service"
4. Click "Connect account" → Authorize GitHub
5. Select your `crmd` repository
6. Fill in details:
   - **Name**: crmd
   - **Runtime**: Docker
   - **Branch**: main
   - **Build Command**: (leave empty)
   - **Start Command**: (docker will use CMD from Dockerfile)
7. Click "Create Web Service"

### 5. Add Environment Variables on Render

1. Go to your service settings on Render
2. Scroll to "Environment"
3. Add new variables:

```
DB_HOST = sql6xxxxx.freemysqlhosting.net
DB_NAME = sql6xxxxx_0
DB_USER = sql6xxxxx_0
DB_PASS = your_password_here
```

4. Click "Save Changes"

### 6. Deploy

1. Render will automatically:
   - Build the Docker image
   - Push to container registry
   - Deploy web service
   - Generate a URL

2. Check deployment logs:
   - Go to "Logs" tab
   - Watch the build and deployment process
   - Look for any errors

3. Your application will be live at:
   ```
   https://crmd-xxxxxx.onrender.com
   ```

### 7. Test Deployment

```bash
1. Visit: https://crmd-xxxxxx.onrender.com
2. Login with: admin / admin123
3. Check dashboard loads
4. Test charts update
5. Add/edit/delete a risk
6. Generate a report
```

## Part 4: Database Backups

### Local Backup

```bash
# Backup local database
mysqldump -u root -p crmd_db > crmd_backup_$(date +%Y%m%d_%H%M%S).sql

# Restore from backup
mysql -u root -p crmd_db < crmd_backup_20260509_101530.sql
```

### Remote Backup

```bash
# Backup remote database
mysqldump -h sql6xxxxx.freemysqlhosting.net -u sql6xxxxx_0 -p sql6xxxxx_0 > remote_backup.sql

# Enter password when prompted
```

## Part 5: Troubleshooting Deployment

### Docker Build Fails

```bash
Check Render logs for specific error
Common issues:
- Missing PHP extensions
- Port configuration
- File permissions
```

### Application Shows "Database Connection Failed"

```bash
1. Verify DB_HOST, DB_NAME, DB_USER, DB_PASS in Render environment
2. Test remote database connection:
   mysql -h <host> -u <user> -p <database>
3. Check if database schema was imported
4. Verify firewall allows connections
```

### Pages Show Blank or 500 Error

```bash
1. Check error logs in Render
2. Check browser console (F12)
3. Verify all includes paths are correct
4. Test database connection
5. Check file permissions (should be 755)
```

### Charts Not Loading

```bash
1. Check browser console for API errors
2. Verify user is authenticated
3. Test api/chart-data.php directly
4. Check database has data
```
